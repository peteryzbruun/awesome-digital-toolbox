A curated collection of digital tools and resources for thinking, creating, building, learning, and organizing work.

## AI Assistants

- [ChatGPT](https://chatgpt.com/) - AI assistant for conversations, writing, research, and working with ideas.
- [Gemini](https://gemini.google.com/) - Google’s AI assistant for conversations, research, and creative tasks.
- [Perplexity](https://www.perplexity.ai/) - AI-powered search and answer tool for researching questions.

## Productivity and Automation

- [Raycast](https://www.raycast.com/) - Launcher for searching, running commands, and automating tasks on macOS.
- [Apple Shortcuts](https://support.apple.com/guide/shortcuts/welcome/ios) - App for combining actions into reusable workflows across Apple devices.
- [Text Blaze](https://blaze.today/) - Text snippets and templates for inserting frequently used content.

## Knowledge and Research

- [NotebookLM](https://notebooklm.google.com/) - Research and note-taking tool for working with selected sources.
- [Raindrop.io](https://raindrop.io/) - Bookmark manager for saving and organizing web resources.
- [Wikipedia](https://www.wikipedia.org/) - Free, collaboratively written encyclopedia covering a broad range of subjects.

## Design and Visual Creation

- [Canva](https://www.canva.com/) - Design platform for creating presentations, graphics, documents, and other visual content.
- [Figma](https://www.figma.com/) - Collaborative design tool for interfaces, prototypes, and visual work.
- [Pixelmator Pro](https://www.pixelmator.com/pro/) - Image editing and design app for macOS.

## Music and Audio

- [Logic Pro](https://www.apple.com/logic-pro/) - Music production app for recording, editing, arranging, and mixing audio.
- [Ultimate Guitar](https://www.ultimate-guitar.com/) - Collection of guitar chords, tablature, and music learning resources.

## Development and GitHub

- [GitHub](https://github.com/) - Platform for hosting repositories and collaborating on software and documentation.
- [GitHub Actions](https://github.com/features/actions) - Automation for building, testing, and managing repository workflows.
- [Visual Studio Code](https://code.visualstudio.com/) - Code editor with extensions for many programming languages and workflows.
